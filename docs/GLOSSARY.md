## Object type

- GLM-5.3-Flash。321,323,031,390 パラメータ、アクティブ 18B、45 層、ルーティングされるエキスパート 288。
- NanoQuant。線形層を低ランクの ±1 行列と全精度スケールに分解する学習後量子化。
- 親チェックポイント。公式 FP8。分解の入力。
- パックしたチェックポイント。±1 をビットに詰めた出力。

## Property

- bitsPerWeightMilli。1000 が 1 bit。
- ramReserveBytes。この機械では 4GiB。KV は含まない。
- ランク。二値因子の列数。ビット予算からスケール分の 16 を引き、32 の倍数へ切り下げる。最小は 32。行数と列数の小さい方を超えるときはそこへ切る。
- 再構成誤差。1 行列について、符号つき再構成と復元した重みの相対フロベニウス誤差。有限でないときは記録しない。数値の上限は置かない。
- 連続因子の比。符号を取る前の積と、復元した重みの相対フロベニウス誤差。記録には残し、ゲートの合否には使わない。

## Link type

- 親チェックポイントからパックしたチェックポイントへ、行列ごとに分解する。
- 親チェックポイントの 1 行列から再構成誤差を記録する。全層の前に行う。
