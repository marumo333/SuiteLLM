# adversarial-review skill（[[0050]] / [[0051]]）

型の正解は `tsc --noEmit` が緑であること。緑の変更をレビューが不正解にしない。検証用の subagent は起動しない。

実装のあと、親が同じ差分を1回だけ読む。この1回は、人がレビューを頼まなくても行う。feature-gate と契約も、人が頼まなくても commit で走る。人が明示するまで止まるのは、追加の Fable 席だけである。指摘は次の4つだけ。

| 分類 | コード | その後 |
| --- | --- | --- |
| 直す | その項目だけ変える | `tsc --noEmit` が緑なら止める |
| 検討 | 変えない | 止める |
| 記録 | 変えない | 止める |
| 却下 | 変えない | 止める |

直すが空なら、そこで止める。直したあとに新しい指摘を探す二周目は開かない。確認するのは `tsc --noEmit` だけ。

同じ1回の読みで、次の3観点を見る。観点ごとに席は増やさない。

| 観点 | 見るもの |
| --- | --- |
| セキュリティ | 秘密、外部送信、権限、取得した文を命令として実行していないか |
| 振る舞い | 観測できる入出力が変わるとき、それを確かめるテストがあるか |
| 設計 | 席、正本、ゲートの境界を増やしていないか |

人がレビューを明示したときだけ、Fable 5.1 を1回起動できる。その1回も同じ3観点と同じ4分類で、直す以外はコードを変えない。観点ごとに起動しない。2回目は `node scripts/review-cap-check.mjs` が拒否する。`skill:verify` と `skill:reflect` は新しい周では 0 回。
